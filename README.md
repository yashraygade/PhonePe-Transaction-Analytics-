# PhonePe-Transaction-Analytics-
🚀 Completed a New Data Analytics Project | PhonePe Transaction Analytics 📊

I’m excited to share my latest Data Analytics project — PhonePe Transaction Analytics, where I analyzed digital payment data to identify transaction trends, regional performance, user activity, and key business insights.

🔧 Tools & Technologies Used:
• Python – Pandas, NumPy, Matplotlib & Seaborn
• Power BI – DAX, KPI Cards & Interactive Visualizations
• CSV – Data Preparation & Analysis

📌 Key Analysis Performed:
• Year-wise and quarter-wise transaction trend analysis
• State-wise transaction volume and transaction value analysis
• Transaction category performance analysis
• User activity and regional engagement analysis
• High-value transaction analysis
• Identification of top-performing and growth-potential regions
